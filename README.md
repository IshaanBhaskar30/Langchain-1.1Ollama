🧪 LangChain Demo using Gemma 2B via Ollama + Streamlit 

This is a lightweight Streamlit application that demonstrates how to use the Gemma 2B model via Ollama in combination with LangChain to build a basic question-answering chatbot. The app uses LangChain's ChatPromptTemplate to structure prompts, tracks interactions using LangSmith, and parses LLM output cleanly via a simple StrOutputParser.

Key features:

->🧠 Ollama backend running Gemma 2B, an efficient open-source LLM by Google

->🔗 LangChain-powered chains for prompt management and output parsing

->📊 LangSmith observability integration for experiment tracking

->💬 Minimalistic Streamlit UI for real-time text-based Q&A interaction

This project serves as a template or starter app for anyone exploring local LLM workflows with Ollama, and how to build structured applications using LangChain components. Ideal for developers who want a quick hands-on setup for testing and deploying lightweight models in a chat-style interface.
